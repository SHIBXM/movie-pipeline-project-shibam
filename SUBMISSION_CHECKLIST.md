# Independent submission checklist

Before submitting, replace every file and artifact that was not created during
your own work on this project. In particular, do not include another learner's
Terraform state, screenshots, Git history, credentials, or downloaded helper
binaries.

- Run the frontend and backend CI workflows from your own repository.
- Provision and deploy only to infrastructure you control, then capture your
  own workflow and application screenshots.
- Keep the deployed image tags tied to your own commits.
- Review every included file and retain only material you created or course
  starter material that the course permits you to use.
- Do not submit until the project can be explained and reproduced by you.
